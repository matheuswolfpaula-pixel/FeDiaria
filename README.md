# FéDiária

"Duolingo da fé católica" em português do Brasil: terço guiado com ofensiva diária, novenas, quiz sobre
Escrituras/Catecismo e orações em latim. Offline, sem anúncios, sem login, sem coleta de dados.

Kotlin Multiplatform + Compose Multiplatform. Android primeiro.

```bash
./gradlew check                      # testes + lint
./gradlew :androidApp:installDebug   # instala no emulador/celular
```

Arquitetura: [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md) · Roadmap: [`docs/ROADMAP.md`](docs/ROADMAP.md)

Conteúdo religioso: apenas textos de domínio público, tradicionais ou originais, todos marcados para revisão
humana antes da publicação.
